Über diese App

SCOOTER RS e-DRIVE ist eine browserbasierte Diagnoseoberfläche für iPhone. Die Verbindung hängt von Browser, Bluetooth-Unterstützung und den tatsächlich vom Scooter angebotenen BLE-Diensten ab.

Es werden keine Zugangsdaten benötigt. Es werden keine Daten an einen Server gesendet.
